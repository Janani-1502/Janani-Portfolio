# Janani P — Portfolio

## Preview locally
1. Open this folder in VS Code.
2. In the Explorer, right-click `index.html` and select **Open with Live Server**.
3. The site should open at `http://127.0.0.1:5500/index.html`. Resize the browser window to check the mobile menu and card layout.

## Files
- `index.html`: page content
- `style.css`: dark responsive design and animations
- `script.js`: mobile navigation, reveal animations, and footer year

## Publish with GitHub Pages
1. Create a new public GitHub repository named `janani-portfolio` without adding a README.
2. In VS Code, open Source Control, initialize Git if prompted, then commit and push `index.html`, `style.css`, `script.js`, and `README.md` to the `main` branch.
3. On GitHub, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then select **Save**.
4. After GitHub finishes publishing, the public address will be `https://janani-1502.github.io/janani-portfolio/`.

Before publishing, verify all profile links and confirm the research publication/patent details are accurate.
